# addons — допы и допродажи

Допы и допродажи для dejavuflowers.ae (Tilda, корзина t706). Своя витрина допов, которая через `tcart__addProduct` кладёт позиции в штатную корзину Tilda.

## Что делает

- **Карточка товара**: подсказка размера под переключателем варианта, плашка «Добавьте шары или сладости к подарку», полка допов под описанием.
- **Попап после «В корзину»**: «Товар добавлен. Дополните подарок» с полкой допов и кнопками «Перейти к оформлению» / «Продолжить покупки». На допы попап не срабатывает.
- **Корзина**: блок «Не забудьте добавить» под товарами (в сайдбаре и на странице корзины). Допы, уже лежащие в корзине, помечены «В корзине».
- **Два шага оформления — штатные Tilda**, свой шаг не добавляем. Десктоп: боковая корзина с допами → «Оформить заказ» → страница с формой (допы там не повторяются). Мобильный: страница корзины с допами, форма за кнопкой «Оформить заказ». «Перейти к оформлению» в попапе ведёт сразу к форме.
- **Выбор параметров**: цвет, размер, фраза, объём, количество, конструктор числа для шаров-цифр (цена × количество цифр).
- **Остатки**: нулевой остаток отключает вариант; остаток передаётся в `inv`, и Tilda сама не даёт положить больше.

## Подключение в Tilda

Блок T123 на всех страницах (или в «Настройки сайта → Вставка кода → перед `</body>`»):

```html
<script>
  window.DV_ADDONS_CONFIG = {
    // подсказки размера: опция → значение → текст
    variantHints: {
      'Размер': { 'S — 25 шт.': 'Корзина: 25 × 20 см', 'M — 51 шт.': 'Корзина: 35 × 30 см' }
    }
  };
</script>
<script src="https://cdn.jsdelivr.net/gh/mirowdav/dejavu-tilda@v0.1.3/addons/src/dv-addons.js" defer></script>
```

### Тест на боевом сайте

Страницы товаров (`/tproduct/...`) строятся по общему шаблону каталога, поэтому скрипт на отдельной тестовой странице до них не дотягивается. Для теста ставим в «Настройки сайта → Вставка кода → перед `</body>`» загрузчик, который включает допы только у того, кто открыл сайт с `?dvtest=1`. Выключить: `?dvtest=0`.

```html
<script>
(function () {
  try {
    if (/[?&]dvtest=1/.test(location.search)) localStorage.setItem('dvtest', '1');
    if (/[?&]dvtest=0/.test(location.search)) localStorage.removeItem('dvtest');
    if (!localStorage.getItem('dvtest')) return;
  } catch (e) { return; }
  var s = document.createElement('script');
  s.src = 'https://cdn.jsdelivr.net/gh/mirowdav/dejavu-tilda@v0.1.3/addons/src/dv-addons.js';
  document.body.appendChild(s);
})();
</script>
```

CSS и `data/addons.json` скрипт подтягивает сам, относительно своего адреса. jsDelivr кэширует ветку `@main` до 12 часов, поэтому на проде подключаем по тегу (`@v0.1.0`) и при релизе ставим новый тег (теги общие на весь репозиторий).

## Данные (`data/addons.json`)

```jsonc
{
  "groups": [{ "id": "balloons", "title": "Шары" }],
  "products": [{
    "id": "heart",              // → артикул в корзине DOP-heart
    "group": "balloons",
    "title": "Шар-сердце",
    "price": 25,                // базовая цена
    "img": "https://...",       // опционально; без фото рисуется кружок цвета
    "type": "digits",           // только для шаров-цифр: цена × кол-во цифр
    "options": [
      { "title": "Размер", "values": [{ "name": "18 см", "price": 25 }, { "name": "45 см", "price": 45 }] },
      { "title": "Цвет", "type": "color", "values": [{ "name": "Красный", "color": "#c8102e", "img": "https://..." }] }
    ],
    "stock": { "45 см / Красный": 0 }   // ключ — значения опций через " / "; нет ключа = не учитываем
  }]
}
```

У значения опции `price` задаёт цену целиком, `add` прибавляет к цене. Позже JSON можно отдавать из NocoDB через n8n: адрес задаётся в `DV_ADDONS_CONFIG.dataUrl`.

- [x] Новый блок каталога (`t-catalog__`) на страницах `/tproduct/...` поддержан.
- [ ] Заказ с допами доходит в заявку и в Stripe с правильной суммой.

## Тест локально

Сохранить страницу товара, вставить перед `</body>` подключение `addons/src/dv-addons.js`, раздать папку через `python3 -m http.server`. Все скрипты Tilda грузятся с CDN, корзина работает по-настоящему.
