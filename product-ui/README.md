# product-ui

Редизайн карточки товара (`/tproduct/...`). Работает с обоими блоками Tilda: новый каталог `t-catalog__` (тестовая /122222) и старый магазин `t-store__` (боевой /catalog); всё делается только в колонке товара, «Также вам может понравиться» не трогаем. Цвета-кружки остаются штатными: галерея со скруглениями, крупные заголовок и цена, «Оформление» карточками с фото, «Размер» кнопками с ценой, широкая кнопка покупки (на мобиле липкая), преимущества под кнопкой. Описание товара скрыто, вместо него блок «Как выглядят размеры».

CSS подтягивается скриптом сам, из той же папки. Картинки вариантов — модуль option-images (класс `dv-optimg-on`).

Цены в кнопках размера берутся из описания товара, строки вида `S 25 шт. — 450 AED`. Тексты преимуществ и ссылка на каталог — в начале `dv-product-ui.js` (`PERKS`, `CATALOG`).

## Допы в карточке

Скрипт сам подгружает модуль [addons](../addons/) из того же тега: полка «Дополните подарок» в карточке, попап после «В корзину», блок в корзине. Внутри карточки полка перекрашена в стиль карточки (4 в ряд, на мобиле лента со свайпом), ссылка «Добавьте шары…» скрыта. Если addons подключён отдельно, второй раз не грузится; отключить: `window.DV_ADDONS_SKIP = true`.

## Как выглядят размеры

Плашка под кнопкой покупки: превью `img/sizes.jpg`, по клику фото открывается на весь экран (закрыть — клик или Esc). Показывается только у товаров с опцией «Размер».

Своё фото или отключение — до подключения скрипта:

```js
window.DV_SIZE_GUIDE = false; // или { title, text, img: 'https://...' }
```

## Тест на боевом сайте

«Настройки сайта → Вставка кода → перед `</body>`». Загрузчик ничего не решает: находит последний тег и подключает [boot.js](../boot.js). Что и когда включать (сейчас — только при `?dvui=1` в адресе), решает boot.js, поэтому Tilda больше не трогаем.

```html
<script>
(function () {
  var repo = 'https://cdn.jsdelivr.net/gh/mirowdav/dejavu-tilda@';
  function load(v) {
    var s = document.createElement('script');
    s.src = repo + v + '/boot.js';
    (document.body || document.head).appendChild(s);
  }
  fetch('https://data.jsdelivr.com/v1/packages/gh/mirowdav/dejavu-tilda/resolved?specifier=latest')
    .then(function (r) { return r.json(); })
    .then(function (d) { load(d.version); })
    .catch(function () { load('v0.1.10'); });
})();
</script>
```

Загрузчик берёт последний тег репозитория через API jsDelivr (ответ кэшируется на 5 минут), поэтому релиз = новый тег, Tilda не трогаем. Ссылка на тег у jsDelivr не устаревает, в отличие от `@main` (тот кэшируется до 12 часов, сброс расходится по серверам минутами, браузер держит файл до 7 дней). Теги общие на весь репозиторий: «последний» — самый старший по номеру. Сразу после пуша тега файлы с CDN не запрашивать — jsDelivr может закэшировать 404; лечится purge по тегу.

Локальная проверка: `before.html` / `after.html` (копии страницы, в git не входят).
