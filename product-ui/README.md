# product-ui

Редизайн карточки товара (`/tproduct/...`). Работает с обоими блоками Tilda: новый каталог `t-catalog__` (тестовая /122222) и старый магазин `t-store__` (боевой /catalog); всё делается только в колонке товара, «Также вам может понравиться» не трогаем. Цвета-кружки остаются штатными: крупные заголовок и цена, «Оформление» карточками с фото, «Размер» кнопками с ценой, широкая кнопка покупки (на мобиле липкая), преимущества под кнопкой. Описание товара скрыто, вместо него блок «Как выглядят размеры».

CSS подтягивается скриптом сам, из той же папки. Картинки вариантов — модуль option-images (класс `dv-optimg-on`).

Цены в кнопках размера — цены вариантов товара из Tilda (данные `var product` на странице товара), с учётом остальных выбранных опций; описание не используется. Количество штук выводится, только если оно есть в названии варианта (`S — 25 pcs`). Картинки «Оформления» (bouquet / box / basket) — фиксированные, `DESIGN_IMAGES` в `dv-product-ui.js`. Все надписи на английском (договор №0311/26: только en.dejavuflowers.ae). Тексты преимуществ и ссылка на каталог — в начале `dv-product-ui.js` (`PERKS`, `CATALOG`).

## Оформления и размеры «по запросу»

У цветочного товара всегда три оформления — bouquet, box, basket (`STYLES`), у каждого фиксированный набор размеров (`SIZE_SETS`): basket — S, M, L, XL, XXL, XXXL; bouquet — S, M, L; box — S, M, L, XL. Что заведено в Tilda (оформления, размеры, в т. ч. вне набора) — остаётся как есть, с ценами. Чего нет — скрипт дорисовывает: недостающее оформление кнопкой с фото (все его размеры «по запросу»), недостающий размер кнопкой «On request». У товара без опции оформления скрипт добавляет свою опцию Style, а варианты из Tilda считает букетом (`window.DV_DEFAULT_STYLE`). Допы (раздел Add-ons 722035005904 или артикул `DOP-`) не трогаются.

При выборе дорисованного вместо цены — «Price on request», «В корзину» кладёт позицию с ценой 0 (артикул `POR-<uid>-<оформление>-<размер>`, опции Size/Style и `Price: on request`) во всех цветах. Кнопки размеров сортируются по букве (S → XXXL), оформлений — всегда bouquet, box, basket (в т. ч. у товаров, где в Tilda другой порядок).

Пока в корзине есть такая позиция, Stripe скрыт и выбраны наличные (обёртка над `tcart__isPaymentUnavailable` — тот же механизм, которым Tilda отключает оплату для доставки). Убрали позицию — Stripe возвращается и снова выбран. Скрываемые способы: `window.DV_POR_BLOCK_PAY` (по умолчанию `['stripe']`), наборы размеров: `window.DV_SIZE_SETS`.

## После «В корзину»

После добавления товара (обычного или «по запросу») сразу открывается предпросмотр корзины `tcart__openCart`: на компьютере боковая панель, на телефоне — страница корзины Tilda. Не добавился (не выбрана опция и т. п.) — ничего не открываем.

## Допы в карточке

Скрипт сам подгружает модуль [addons](../addons/) из того же тега: блок в корзине (попап после «В корзину» выключен). Полка «Дополните подарок» в карточке выключена с 21.11.2026 (`productShelf: false` в addons), поле цифр у шаров-цифр работает. Полка переставляется после опций, перед количеством/кнопкой «В корзину»; перекрашена в стиль карточки (3 в ряд, на мобиле лента со свайпом), ссылка «Добавьте шары…» скрыта. Если addons подключён отдельно, второй раз не грузится; отключить: `window.DV_ADDONS_SKIP = true`.

## Как выглядят размеры

Плашка под кнопками размера, по клику фото открывается на весь экран (закрыть — клик или Esc). Картинка задаётся в карточке товара в Tilda: характеристика **Size guide**, значение — ссылка на картинку. Нет характеристики — нет плашки; сама характеристика на странице скрывается.

Своё фото или отключение — до подключения скрипта:

```js
window.DV_SIZE_GUIDE = false; // или { title, text, img: 'https://...' }
```

## Подключение на сайте

С 19.11.2026 — прямая ссылка на конкретный тег в «Настройки сайта → Вставка кода → перед `</body>`», без загрузчика и сверки версий:

```html
<script src="https://cdn.jsdelivr.net/gh/mirowdav/dejavu-tilda@0.1.52/product-ui/dv-product-ui.js"></script>
```

Скрипт сам подключает свой CSS и модуль addons из того же тега. Новая версия на сайте = новый тег + смена номера в этой ссылке. Сразу после пуша тега файлы с CDN не запрашивать — jsDelivr может закэшировать 404; лечится purge по тегу.

Встроить весь код в Tilda не получилось: поле HEAD обрезается (~55 КБ вместе с gallery-filter), незакрытый `<script>` даёт белый экран.

Локальная проверка: `before.html` / `after.html` (копии страницы, в git не входят).
