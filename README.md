# dejavu-tilda

Кастомный код для сайта [dejavuflowers.ae](https://dejavuflowers.ae) на Tilda.

Скрипты раздаются через jsDelivr и подключаются в Tilda по тегу версии:

```
https://cdn.jsdelivr.net/gh/mirowdav/dejavu-tilda@<tag>/<модуль>/...
```

## Модули

| Папка | Что делает | Где подключено в Tilda |
|---|---|---|
| [addons/](addons/) | Допы (шары, клубника, Зелинский) и допродажи: попап после «В корзину», блок в корзине, 2 шага оформления | тест: страница /122222 (T123) |
| [gallery-filter/](gallery-filter/) | Фото товара по выбранным опциям (цвет, размер, оформление) по alt-тегам, заглушка если фото нет | весь сайт, HEAD; ссылка `@main` |
| [product-ui/](product-ui/) | Редизайн карточки товара: фото, варианты карточками, размер с ценой, липкая кнопка на мобиле | тест: перед `</body>` с `?dvui=1` |

## Релиз

1. Закоммитить изменения в `main`.
2. Поставить тег: `git tag v0.2.0 && git push --tags`.
3. В Tilda поменять версию в ссылке и переопубликовать страницы.

Модули на `@main` (gallery-filter) обновляются без правки Tilda: после пуша сбросить кэш jsDelivr по каждому изменённому файлу:

```
curl -s https://purge.jsdelivr.net/gh/mirowdav/dejavu-tilda@main/<модуль>/<файл>
```

Откат — вернуть в ссылке прежний тег. Ветку `@main` jsDelivr кэширует до 12 часов, поэтому на проде её не используем.

Секретов (токены NocoDB, ключи n8n) в репозитории нет и не должно быть: репозиторий публичный.
