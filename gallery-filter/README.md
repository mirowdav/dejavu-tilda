# gallery-filter — фото товара по выбранным опциям

В карточке товара Tilda показывает только фото, подходящие под выбранные опции (цвет, размер, оформление и т.д.). Работает в модулях «Магазин» (`t-store`) и «Каталог» (`t-catalog`).

## Как работает

- Для каждого фото в редакторе Tilda заполняется поле **Alt** — значения опций через `;`, например `Розовый;M — 51 шт.` или `M — 51 шт.;Букет`. Порядок не важен, значения должны дословно совпадать с названиями вариантов.
- При открытии карточки и при смене любой опции в галерее остаются фото, у которых в alt есть **все** выбранные значения.
- Нет фото под выбранную комбинацию — показывается заглушка (`PLACEHOLDER_IMAGE` в начале файла, пустая строка отключает).
- Фото без alt после фильтрации не показываются. Если у товара нет ни одного alt, скрипт его не трогает: галерея штатная.
- Работает при прямом заходе на страницу товара и при открытии из каталога без перезагрузки (перехват `history.pushState`).

## Подключение в Tilda

Один раз на весь сайт: «Настройки сайта → Ещё → HTML-код для вставки внутрь HEAD»:

```html
<script src="https://cdn.jsdelivr.net/gh/mirowdav/dejavu-tilda@main/gallery-filter/src/gallery-filter.js" defer></script>
```

Ссылка постоянная (`@main`): правки в скрипте попадают на сайт без смены ссылки.

## Обновление

1. Правка в `gallery-filter/src/gallery-filter.js`, коммит и пуш в `main`.
2. Сбросить кэш jsDelivr (иначе до 12 часов отдаётся старая версия):

```
curl https://purge.jsdelivr.net/gh/mirowdav/dejavu-tilda@main/gallery-filter/src/gallery-filter.js
```

## Отладка

Все шаги пишут в консоль с префиксом `[gallery-filter]`: какие опции выбраны, какие группы alt подошли, сколько фото показано.

## Ограничения

- Скрипт полностью перестраивает слайдер и миниатюры, а клики по миниатюрам обрабатывает сам (Tilda вешает их один раз при инициализации).
- Если подключить скрипт дважды, второй экземпляр ничего не сделает (защита `window.__galleryFilterLoaded`).
